Help & FAQ

Start here. Most problems have a specific, honest error message — this page explains what each one means.

①

Connect

Sign in with GitHub and import a repo, paste a public URL, upload a folder, or start from a template.

②

Configure

Check the detected framework and commands, add environment variables, create the project.

③

Deploy

Press deploy and watch the real log. After that, every git push ships by itself.

Sign-in says GitHub is “not set up” or “not configured”

The server has no GitHub OAuth credentials. If you run this site, set GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET and SESSION_SECRET as Worker secrets and register the callback URL (see self-hosting). If you are a user, the operator needs to finish setup.

“Repository not found” for a repo I own

Private repositories need sign-in, and the repository URL import checks with your account. Make sure you are signed in with the account that can see it, and that the organization has not blocked the OAuth app.

Uploads are “not enabled”

Folder and zip uploads are stored in Cloudflare R2. They work only when the operator has bound an R2 bucket as UPLOADS. Until then, import from Git instead. Uploads are limited to 50 MB and 1000 files.

“Deploy failed: build pipeline is unreachable / not configured”

Deploys are executed by an external build pipeline. This message means DEPLOY_WEBHOOK_URL or DEPLOY_WEBHOOK_SECRET is missing, the pipeline is down, or it answered with an error. The exact reason is shown in the log. Fix the pipeline, then press Retry deploy. See the pipeline contract.

The webhook says “admin access required” or “not configured”

Git push = deploy needs admin rights on the repository (to add a webhook) and a server-side GITHUB_WEBHOOK_SECRET. Without them the project is created, but you redeploy manually from the dashboard.

Why can’t I see my environment variable values?

They are write-only by design. Values are encrypted at rest and only names are ever returned to the browser. To change one, create it again with a new value.

How do I redeploy?

Open the dashboard, pick the project and press Redeploy. For GitHub projects with an active webhook, pushing to the default branch does it for you.

“Template repository not found”

Templates are real GitHub template repositories configured by the operator in the TEMPLATES variable. If the repository was renamed, deleted or isn’t marked as a template, GitHub refuses and the error is shown as-is.

I found a bug or want my data removed

Open an issue at github.com/thanabartbb/aibotq-site/issues. You can also revoke access any time in GitHub → Settings → Applications. More in the privacy policy.
